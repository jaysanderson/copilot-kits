# Fonts

Progress Sans (`ProgressSansDisplayVF.woff2`, `ProgressSansTextVF.woff2`) is a licensed brand font and is not in this repo. Every `brand/fonts/` folder is gitignored for it. Get the two files from the Progress brand portal and drop them into each `brand/fonts/` (and `video/templates/launch-film/assets/`). Every stylesheet falls back to Inter or the system sans-serif until then. Poppins, where present, is Open Font Licence and stays in the repo.
