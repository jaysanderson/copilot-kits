## TYPOGRAPHY (Face | Role | Rules)

Progress Sans Display | Headlines, hero areas, anything read at a glance | Never mixed with Text within one sentence, paragraph or title; roles never reversed.
Progress Sans Text | Body copy, ALL UI elements, captions, labels | The workhorse; UI is always Text, never Display.
Arial | The ONLY approved substitute when Progress Sans is unavailable | Not Helvetica, not Inter, not a system stack.
Roboto Mono | Code, and only code | Never decorative.
(Type rules) | Cross-cutting | Type is predominantly black on light and white on dark; colour in type is a selective accent (links, states, emphasis), never the default for headings/body. No adjacent-weight mixing in a block. Minimum 6.5pt. Tracking/leading tuned, not default.

## VOICE_TONE

Plain, direct, practitioner language - no corporate fluff. Product naming: "Progress(R) Agentic RAG" on first prominent use; never abbreviate to "ARAG" in customer-facing copy. Every claim substantiated - no fabricated statistics, no accuracy percentages (quality is demonstrated live). Spaced hyphens, not em dashes. Approved phrasing and the banned-word list render live from the messaging pillars (one source, never a copy).

## MOTIF_RULES (Hex Loop)

Always CROPPED, bleeding off an edge of the layout - never a complete hexagon, never standalone, never competing with the logo. Original Agentic RAG blues only (#2B2BB2 / #00123C ramp) - never recolored. Note: the source brand page's line about "primary oranges" is a known defect inherited from another product's page; the artwork is authoritative and the Hex Loop is blue. Stays on the 30-degree isometric grid - never rotated off it. One crop per layout; multi-product or cross-sell material uses the Progress Helix instead, never two Hex Loop crops.

## USAGE_NOTE (logo + general)

The logo carries Progress CORPORATE colours - Logo Green #5CE500 and Logo Gray #4B4E52 - never the Agentic RAG palette greens; substituting palette green into the symbol breaches trademark guidelines, not just brand ones. Always use supplied files, never redrawn/traced/re-typeset. Horizontal lockup preferred; stacked only when space genuinely forces it. Clear space: half the symbol height on all sides. Minimum size: 75px high on screen, 0.85in in print. No effects (shadow, bevel, gradient, outline, opacity), no stretching, no rotation, no removed elements. Blues and greens must predominate in every layout; yellow and red are illustration accents only. Never put green text or small green UI elements on a light background.
