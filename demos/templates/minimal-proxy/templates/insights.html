How this works

Everything on this page is read from the app's own log of questions asked on the student front door. Nothing is sample data.

1. Someone asksThe question goes from their browser to this app's own server, in whichever language they chose.
↓
2. Progress Agentic RAG answers, or declinesThe server asks it over the site's content. The answer comes back with citations, or with a decline when nothing sourced supports one. The server itself labels which.
↓
3. The app logs one rowA small logger on the same server notes: the question text, the language chosen, answered or declined (that server label), how many pages were cited and their addresses, and the time taken. A failed request is logged as an error, never as a decline.
↓
4. This page reads the logCounts, groups and the language split are calculated from those rows when the page loads. The team tag is set only when a request carries a secret key held by the build team. Any other question is tagged direct: the log identifies nobody, so it cannot tell a presenter, a tester and a visitor apart, and it does not pretend to.

What is never recorded: IP address, device or browser details, cookies, account or session identifiers. A row cannot be traced to a person.

Questions are answered from university.edu.au content by Progress Agentic RAG. This page is a live read of the question log: it contains only questions that were actually asked.
