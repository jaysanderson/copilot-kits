What the web team pasted

Two lines. No framework, no build step, no package install. The styles live in a shadow root, so nothing on this page can restyle the widget and the widget cannot restyle this page.

<script src="{{ origin }}/static/embed/widget.js" async></script>
<div data-ask-widget data-langs="en,zh" data-accent="#c2410c"></div>

Everything that differs between the two boxes above is a data attribute on the mount point. Nothing was forked.

AttributeWhat it changes
data-langsLanguages offered, first one is the default. en,zh,ar,id
data-accentButtons, citation badges, links, focus ring.
data-placeholderCopy in the question box.
data-scopeWhich part of the site answers. Omit for the whole site, or name a section such as study or research. The server checks every cited page sits inside it.

The page you are reading has no access to the knowledge base. The widget sends the question to the server that served the script. That server holds the credential, calls Progress Agentic RAG and returns the answer with its source pages. No key, token or knowledge base address is in this page or in the script.

Every answer is a live call at the moment you ask. The sources are the real pages the answer was drawn from.

Westbound Student Network is a fictional organisation used to show the embed. The answers come from the public The university website.
